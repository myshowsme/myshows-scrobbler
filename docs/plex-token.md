# Plex: как найти токен и адрес сервера

Обычно токен и адрес подставляются сами: кнопка **«Найти токен»** читает `Preferences.xml` из папки данных локального Plex Media Server. Но если она отвечает «локальный Plex Media Server не найден», значит файл лежит не там, где скробблер его ищет. Три обычные причины:

- **Папка данных Plex перенесена** на другой диск (частое дело, когда библиотека большая) — путь задан в реестре, в значении `LocalAppDataPath`.
- **Plex запущен под другой учётной записью Windows** — например, поставлен как служба или под учёткой администратора. Тогда его настройки лежат в профиле того пользователя, а не вашего.
- **Настройки хранятся только в реестре**, файла `Preferences.xml` на диске нет вовсе.

Во всех трёх случаях токен вводится вручную — ниже все способы его получить.

> **Токен — это ключ от вашего аккаунта Plex.** Он даёт полный доступ к серверу и библиотеке. Не публикуйте его в issue, логах и скриншотах.

---

## Способ 1. Windows: реестр (самый быстрый)

Plex на Windows дублирует `PlexOnlineToken` в реестре текущего пользователя.

**PowerShell** — откройте меню «Пуск», наберите `PowerShell`, вставьте одну строку:

```powershell
(Get-ItemProperty "HKCU:\Software\Plex, Inc.\Plex Media Server").PlexOnlineToken
```

В ответ придёт строка из 20 символов — это и есть токен.

**Или через regedit:** `Win + R` → `regedit` → перейдите по пути

```
HKEY_CURRENT_USER\Software\Plex, Inc.\Plex Media Server
```

и посмотрите значение **`PlexOnlineToken`** (правый клик → «Изменить» → скопировать строку).

> Если PowerShell вернул пустую строку или ветки в реестре нет — Plex Media Server запущен под **другой учётной записью Windows** (частый случай: сервер поставлен как служба или под учёткой администратора). Токен лежит в реестре того пользователя, под которым работает Plex. Проще всего тогда взять токен способом 2.

**Другие ОС:**

| ОС                | Где лежит `PlexOnlineToken`                                                                                            |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Windows**       | `%LOCALAPPDATA%\Plex Media Server\Preferences.xml`, плюс копия в реестре: `HKCU\Software\Plex, Inc.\Plex Media Server` |
| **macOS**         | `~/Library/Preferences/com.plexapp.plexmediaserver.plist`                                                              |
| **Linux (пакет)** | `/var/lib/plexmediaserver/Library/Application Support/Plex Media Server/Preferences.xml`                               |
| **Docker / NAS**  | `<том с конфигом>/Library/Application Support/Plex Media Server/Preferences.xml`                                       |

**Если папка данных Plex перенесена**, её корень записан в том же разделе реестра:

```powershell
(Get-ItemProperty "HKCU:\Software\Plex, Inc.\Plex Media Server").LocalAppDataPath
```

Файл с токеном тогда лежит в `<этот путь>\Plex Media Server\Preferences.xml`.

## Способ 2. Plex Web: «Просмотр XML» (работает везде)

Официальный способ Plex, не зависящий от ОС и от того, под кем запущен сервер.

1. Откройте Plex Web: [app.plex.tv](https://app.plex.tv) или `http://127.0.0.1:32400/web` — и войдите в свой аккаунт.
2. Откройте **любой** фильм или серию в библиотеке.
3. Нажмите **⋯** (три точки) → **«Получить информацию» / Get Info**.
4. В нижней части окна с информацией нажмите **«Просмотр XML» / View XML** — откроется новая вкладка.
5. Посмотрите на **адресную строку** этой вкладки. В самом её конце будет:

   ```
   ...?checkFiles=1&...&X-Plex-Token=xxxxxxxxxxxxxxxxxxxx
   ```

   Скопируйте то, что идёт после `X-Plex-Token=` — 20 символов до конца строки или до следующего `&`.

## Способ 3. Токен аккаунта из браузера

Если Plex Web уже открыт, токен можно достать из хранилища страницы.

1. На вкладке с [app.plex.tv](https://app.plex.tv) нажмите `F12` (DevTools) → вкладка **Console**.
2. Вставьте и выполните:

   ```js
   localStorage.getItem('myPlexAccessToken')
   ```

3. Скопируйте строку из кавычек.

Это токен аккаунта — он подходит к любому вашему серверу.

## Где взять адрес (URL) сервера

В поле **URL** скробблера нужен адрес API Plex, порт по умолчанию — **32400**.

| Где стоит Plex                            | Что вписывать                                                               |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| На **той же машине**, что и скробблер     | `http://127.0.0.1:32400` (значение по умолчанию — менять не нужно)          |
| На **другом компьютере/NAS в вашей сети** | `http://192.168.x.x:32400` — локальный IP машины с Plex                     |
| Через интернет                            | `https://<ваш-хеш>.plex.direct:32400` — берётся из адресной строки Plex Web |

**Как узнать локальный IP машины с Plex:**
Plex Web → **Настройки** (гаечный ключ) → ваш сервер → **Удалённый доступ**: там показан адрес и порт, по которым сервер виден. Или в **Настройки → Сеть**, поле «Список IP-адресов и портов, доступных снаружи».

**Как проверить адрес, не имея токена.** Откройте в браузере:

```
http://127.0.0.1:32400/identity
```

Живой Plex отвечает XML вида:

```xml
<MediaContainer size="0" apiVersion="1.2.2" claimed="1"
  machineIdentifier="1216627cc55263373ac8faa5d1946979c6ba5242"
  version="1.43.3.10828-00f62d37d" />
```

Если страница не открылась — дело в адресе, порте или брандмауэре, а не в токене.

## Проверка связки «адрес + токен»

Откройте в браузере, подставив свои значения:

```
http://127.0.0.1:32400/status/sessions?X-Plex-Token=ВАШ_ТОКЕН
```

- **XML со списком сессий** (пустой `<MediaContainer size="0">`, если сейчас ничего не играет) — всё верно, вставляйте эти же значения в скробблер.
- **`401 Unauthorized`** — токен неверный или скопирован не полностью.

## Частые проблемы

**«локальный Plex Media Server не найден» на Windows.**
Скробблер не нашёл `Preferences.xml` в стандартной папке данных. Причины и что проверить — в начале этой страницы; токен берётся способом 1 или 2 и вставляется вручную.

**`Invalid Plex token (401)` в логе событий.**
Поле токена пустое или в нём лишние пробелы/обрезанная строка. Токен — ровно 20 символов, без пробелов по краям. Проверьте связку ссылкой из раздела выше.

**`Unexpected token '<', "<!DOCTYPE "... is not valid JSON`.**
По указанному адресу отвечает не API Plex, а веб-страница. Проверьте, что в поле URL нет `/web` и лишнего пути — нужен голый `http://127.0.0.1:32400`.

**Отметки не приходят, хотя всё подключилось.**
Токен должен принадлежать **владельцу сервера**. Токен managed-пользователя или гостя не видит чужие сессии в `/status/sessions`.
